CarWise AI is an AI-powered contract intelligence platform that helps users understand vehicle contracts, detect hidden risks, and make smarter decisions before signing.

## Overview

- AI-driven contract analysis for vehicle-related documents
- Risk highlighting and clause understanding
- Secure document upload and analysis workflow
- Dashboard for contract history and insights

## Tech Stack

- Frontend: React.js, Vite, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Integration: Gemini AI
- APIs: REST APIs

## Project Structure

- `client/` — Frontend application
- `server/` — Backend server and APIs
- `ai-service/` — AI analysis service
- `shared/` — Shared utilities and constants

## Features

- Upload and analyze contracts
- Detect important clauses and hidden charges
- Generate risk-based summaries
- Browse contract history and review insights

## Run Locally

### 1. Install dependencies

```bash
cd client
npm install

cd ../server
npm install

cd ../ai-service
npm install
```

### 2. Start the applications

```bash
cd client
npm run dev

cd ../server
npm run dev

cd ../ai-service
npm start
```
